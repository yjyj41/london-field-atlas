# Data and asset attribution

## Geographic data

© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). OpenStreetMap data is available under the [Open Database Licence 1.0](https://opendatacommons.org/licenses/odbl/1-0/). The derived footprint and height dataset is supplied in `assets/city-data.zip`. Keep the attribution and comply with the applicable database licence when redistributing or adapting that data.

Architectural models include estimated heights and interpreted forms. Source links and model limitations appear in each building's metadata. They are not surveyed reconstructions.

## Photographs

Each photograph has its own author, source URL, licence and licence URL in the corresponding `photo` record in `assets/city.json`. The website displays these credits beneath the image. Images have been resized and compressed for web delivery. Preserve the individual credits and follow the linked licence when reusing an image.

## Software dependencies

- Three.js and its bundled loaders/utilities: see `vendor/LICENSE` and source headers.
- fflate: see the licence notice in `vendor/fflate.module.js`.
- Rhino3dm: see the licence files distributed in `vendor/rhino/` and [the upstream project](https://github.com/mcneel/rhino3dm).

The licences of these components remain in effect independently of the atlas application.
